# Data (as built at Milestone 1)

All data are synthetic, generated by `python -m fcip.cli simulate --profile <profile> --seed <seed>`.
Authoritative schemas: `src/fcip/common/schemas.py`. Entity-relationship model: `docs/PHASE0_ASSESSMENT.md`
section 4.5. Conventions: time is int64 seconds since the simulation epoch (day 0 is Monday 2025-01-06 for
seasonality only); money is int64 minor units of the single synthetic currency `SYN` (100 per major unit, declared
once in `metadata.json`; no per-row currency column, S3).

## Tables

| Table | Kind | Primary key | Notes |
|---|---|---|---|
| `persons` | observable | `person_id` | region, household, creation time |
| `accounts` | observable | `account_id` | internal and external (employer, biller, landlord, external world, card network, cash) |
| `devices`, `ips`, `atms`, `merchants` | observable | id | IP context (household, public Wi-Fi, corporate NAT, carrier NAT, residential) |
| `relations` | observable | `(relation_type, src_id, dst_id, valid_from)` | OWNS_ACCOUNT, CONTROLS, USES_IP with validity |
| `transactions` | observable | `event_id` | status, balances before/after on both sides; APP/WEB rows reference a login |
| `logins` | observable | `event_id` | account, device, IP, channel, outcome |
| `person_truth` | **oracle** | `person_id` | archetype, origin (normal or scenario-created) |
| `labels` | **oracle** | `(entity_type, entity_id, scenario_id, valid_from)` | phase-dependent role intervals starting at the member's first own event (A1), `known_at` |
| `event_labels` | **oracle** | `(event_table, event_id)` | scenario events: phase, event type, high-risk and terminal flags |
| `ground_truth_networks` | **oracle** | `network_id` | family, OOD flag, timing, terminal / censored / detected, drawn instance parameters |
| `network_members` | **oracle** | `(network_id, entity_type, entity_id)` | first role, join time (first own event) |

Oracle tables are ground truth for evaluation and description only. Model and feature code must read data through
`fcip.temporal.store.TemporalStore`, which loads only observable tables plus label rows that can ever be known.

## Identity and provenance

`metadata.json` records the resolved config and its hash, seed, generator commit and status, package versions,
per-table content hashes and the dataset hash (`fcip-content-hash-v1`, decision 0001), per-file SHA-256, activation
report, realized prevalence and recruitment shortfall. `python -m fcip.cli validate --data <dir>` recomputes the
dataset hash and re-runs all invariant checks.

## Profiles

| Profile | Persons | Days | Purpose |
|---|---|---|---|
| `tiny` | 400 | 45 | unit tests only |
| `dev` | 2,500 | 90 | fast iteration and end-to-end test; forces one instance per family, so prevalence is above target |
| `research` | 100,000 | 90 | gates and experiments; prevalence follows the 1% quota |

Measured sizes and statistics are in `reports/eda_milestone1.md`.
